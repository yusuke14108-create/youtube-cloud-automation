# ニュースch 動画自動投稿システム

ニュースch 動画自動投稿システムは、運営者本人が管理する3つのYouTubeチャンネル向けに、動画を作成・確認・予約投稿するための非公開の運用ツールです。

Googleアカウントへのアクセスは、運営者本人がYouTubeへの動画投稿とチャンネル情報の確認を許可した場合に限って使用します。第三者向けのログインサービスではありません。

- 対象: 医療、MLB、NBAの各YouTubeチャンネル
- 用途: チャンネル確認、動画の非公開アップロード、公開日時の設定、運用結果の確認
- 問い合わせ先: yusei14108@gmail.com
