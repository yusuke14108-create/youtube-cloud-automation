# プライバシーポリシー

最終更新日: 2026年8月22日

ニュースch 動画自動投稿システム（以下「本システム」）は、運営者本人が管理するYouTubeチャンネルの動画投稿を自動化するために使用します。

## 取得するGoogleユーザーデータ

本システムは、Google OAuthによる明示的な許可に基づき、次の情報へアクセスします。

- YouTubeチャンネルのID、名称など、投稿先を確認するための基本情報
- 本システムがアップロードまたは管理する動画のID、公開状態、公開予定日時など
- YouTube Analytics APIから得られる、運営者本人のチャンネルおよび動画の集計済み分析情報

Googleアカウントのパスワード、MFAコード、支払い情報は取得しません。

## 利用目的

取得した情報は、正しいチャンネルへの動画アップロード、公開日時の設定、投稿結果の確認、品質改善のための分析にのみ使用します。

## 保存と保護

OAuth認証情報は、運営者本人が管理する端末およびGitHub Actionsの暗号化されたSecretsに保存します。公開リポジトリ、動画、ログには認証情報を掲載しません。必要な範囲を超えてGoogleユーザーデータを複製・保存しません。

## 共有

Googleユーザーデータを販売しません。また、法律上必要な場合を除き、第三者へ共有しません。動画作成・投稿処理を実行するため、GoogleのYouTube APIおよび運営者本人が管理するGitHub Actionsを利用します。

## データの削除とアクセス権の取消し

運営者は、Googleアカウントの「サードパーティ製のアプリとサービス」設定から本システムのアクセス権をいつでも取り消せます。保存済み認証情報と処理記録の削除は、下記問い合わせ先へ依頼できます。

## Google API Services User Data Policy

本システムによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)（Limited Use要件を含む）に従います。
